## 決めごと・注意

- Windows から `G:` に**書かない**（`_from_windows` 以外）。台帳 xlsx は Mac が正本。
- 帳票を Windows で回すときは、Mac 側で同じ台帳を開いていないことを確認してから。
- 数 GB の映像・.blend は `G:` に置かない。SSD か `C:\YBJ`。
- Blender GUI は 5.2、bpy は 4.2。4.2 で作った .blend は 5.2 で開けるが、5.2 で保存し直すと bpy 4.2 で読めない。その場合は `blender.exe -b --python` で回す。
- RTX 50 系は CUDA 12.8 以降が必須（torch は cu128）。ffmpeg 9 の NVENC はドライバ 610 以上。
- Gemini キーは今日 3 回画面に出た。気になるなら AI Studio で再発行 → Windows は `.\04_secrets.ps1 -Force`、Mac は `~/.bolero-senden.env` を書き換え。
- OpenAI API は未接続（Mac にも無い）。GPT Image を使いたくなったら `platform.openai.com` でキーを作り `.\04_secrets.ps1`。

## 今日ぶつかって直したこと（次回のため）

| 症状 | 原因 | 対処（スクリプトに反映済み） |
|---|---|---|
| `git` が認識されない | 入れた直後の同じウィンドウでは PATH が古い | ターミナルを開き直す |
| `npm install -g @anthropic-ai/claude-code` 失敗 | npm error code 1 | 公式 `irm https://claude.ai/install.ps1 \| iex` に変更。`.local\bin` を PATH に追加 |
| `claude` が npm の残骸を指す | 失敗した npm が `%APPDATA%\npm\claude*` を残す | 残骸を削除 |
| Python の版確認で SyntaxError | PowerShell 5.1 が `python -c` 内の `"` を剥がす | `-c` に引用符を使わない書き方に |
| `git pull` が衝突 | 初回 clone が autocrlf=true で CRLF、後で false に | `git checkout -- .` で捨てて pull |
| NVENC が `Driver does not support` | ドライバ 591 < 610 | Studio ドライバ 616.92 へ |
| WSL の検証で SyntaxError | PS → bash の引用符崩れ | 検証を `wsl-check.sh` に分離 |
| Google Drive がスタートに無い | インストール直後は未起動 | `launch.bat` を直接実行 |
| Ubuntu が自動で開かない | 再起動後に自動起動しないことがある | `wsl --install -d Ubuntu` を再実行 |
| API キーの右クリック貼り付けが空 | クリップボードが後でコピーした命令に上書き | 「スクリプト起動 → キーをコピー → Ctrl+V」の順に |
